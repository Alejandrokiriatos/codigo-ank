1. OBJETIVO GENERAL DEL PROYECTO
================================================================

Transformar Código ANK para eliminar la dependencia de OpenCode y permitir que cualquier usuario conecte proveedores de inteligencia artificial mediante sus propias API. La aplicación debe servir como entorno de trabajo donde distintos modelos/proveedores puedan operar dentro del proyecto, manteniendo una experiencia coherente tanto en móvil como en escritorio.

El desarrollo debe continuar sobre la rama ank/block-3-multiple-api. No trabajar directamente sobre main ni mezclar este trabajo con la rama principal sin una revisión y autorización explícitas.

El workflow reconstruye una APK temporal a partir de decoded/, inyecta un
harness de CI no persistente en index.html y ejecuta el servicio Cordova
System real dentro de un emulador Android API 30. La secuencia automatizada:
1. securePut con valor aleatorio desechable.
2. secureGet y comparación exacta dentro del WebView.
3. force-stop del proceso Android.
4. Segundo arranque y secureGet del valor persistido.
5. secureRemove y secureGet vacío.

El harness no registra el secreto, no se incluye en commits ni en APK release,
y la clave de firma de CI es efímera. La prueba acredita persistencia después
de muerte del proceso si el job termina en success. No acredita reinicio del
sistema operativo, migración de instalación ni prueba física en TECNO.

El workflow se activa en cambios del código Android y de estos documentos.
No modificar main ni publicar el APK temporal.
